# Spec Delta: class-isolation

## Purpose

把班级作为数据边界，保证任何列表、详情、检索与统计都只覆盖当前账号所在班级，跨班数据不可见。

## ADDED Requirements

### Requirement: 班级来源唯一

系统 MUST 从会话读取当前账号的班级，忽略客户端请求中携带的班级参数；所有业务查询 SHALL 以该班级作为强制过滤条件。

#### Scenario: 请求体伪造班级
- **WHEN** 请求体中携带其他班级的 `class_id`
- **THEN** 结果仍限于会话所属班级，伪造字段不生效

### Requirement: 列表与检索的班级过滤

系统 SHALL 在讲义列表、检索结果与统计中使用同一班级条件，不得出现某处过滤、某处不过滤的情况。

#### Scenario: 两个班级各自检索
- **GIVEN** 一班和二班各自上传了同名讲义
- **WHEN** 一班学生检索该主题
- **THEN** 只返回一班的片段，来源文件也属于一班

### Requirement: 跨班与不存在一致

系统 MUST 让跨班访问与访问不存在的资源返回相同的状态与结构。

#### Scenario: 跨班读取详情
- **WHEN** 二班教师按 ID 读取一班的讲义
- **THEN** 返回 404，与读取不存在 ID 的响应一致
