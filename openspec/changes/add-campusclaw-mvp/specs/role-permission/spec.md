# Spec Delta: role-permission

## Purpose

明确教师与学生的能力边界，把判定放在服务端，并采用默认拒绝，避免页面隐藏代替接口校验。

## ADDED Requirements

### Requirement: 角色能力矩阵

系统 SHALL 按角色限制操作：教师可上传与管理本班讲义、使用检索；学生只可查看与检索本班讲义，不可上传、不可修改任何材料；两端都不可修改账号角色或班级归属。

#### Scenario: 学生尝试上传
- **GIVEN** 学生已登录
- **WHEN** 调用讲义上传接口
- **THEN** 返回 403，且不产生任何记录

#### Scenario: 学生尝试修改角色
- **WHEN** 学生在请求体中携带 `role` 或 `class_id` 字段
- **THEN** 服务端忽略这些字段，身份仍以会话为准

### Requirement: 默认拒绝

系统 MUST 对未显式授权的接口与操作返回 403；新增接口未登记权限时默认不可访问。

#### Scenario: 未登记接口
- **WHEN** 调用一个未在权限表中声明的接口
- **THEN** 返回 403，而不是按登录状态放行

### Requirement: 越权与不存在响应一致

系统 SHALL 对无权限的资源与不存在的资源返回相同状态与结构，避免通过响应差异推断数据是否存在。

#### Scenario: 访问其他班级资源
- **WHEN** 教师访问非本班讲义详情
- **THEN** 返回 404，响应体与不存在的 ID 一致
