# Spec Delta: material-upload

## Purpose

让教师把讲义安全地放进本班知识库，并让上传后的状态可追踪、失败可重试、原文可核对。

## ADDED Requirements

### Requirement: 仅教师上传，且限定格式与大小

系统 SHALL 只允许教师向本班上传 `.txt` 与 `.md` 文件，并限制单文件大小；超限或格式不符 MUST 拒绝且不产生半条记录。

#### Scenario: 学生上传
- **GIVEN** 学生已登录
- **WHEN** 上传任意文件
- **THEN** 返回 403，材料数量不增加

#### Scenario: 格式不符或超限
- **WHEN** 上传 `.pdf` 或超过大小上限的文件
- **THEN** 返回 400，说明具体原因，数据库中不新增记录

### Requirement: 原文保存与索引状态

系统 SHALL 先保存原文与材料记录，再异步建立索引；状态 MUST 明确区分「索引中」「可用」「失败」，不得把索引中显示为可用。

#### Scenario: 上传成功
- **WHEN** 教师上传一个合法 Markdown 文件
- **THEN** 返回材料 ID，状态先为「索引中」，索引完成后变为「可用」

#### Scenario: 索引失败可重试
- **GIVEN** 某材料索引失败
- **WHEN** 教师触发重试
- **THEN** 状态回到「索引中」，成功后变为「可用」，原文保持不变

### Requirement: 原文可核对且受班级约束

系统 SHALL 允许本班成员下载原文，且只能下载本班材料；不得通过猜路径绕过鉴权。

#### Scenario: 跨班下载原文
- **WHEN** 其他班级成员请求该材料的原文地址
- **THEN** 返回 404，不返回文件内容
